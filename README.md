# Back-End Development

Learning and documentation for backend development.

## Topics

- Node.js — modules, event loop, async/await
- Express — routing, middleware, request/response handling, error handling
- PostgreSQL — queries, connection pooling, migrations
- Authentication — JWT, bcrypt, OAuth, sessions
- Validation & Security — input validation, helmet, CORS, rate limiting
- REST API Design — versioning, pagination, filtering, sorting, status codes
- Production — logging, testing, CI/CD, deployment
- Advanced — caching (Redis), message queues, WebSockets
